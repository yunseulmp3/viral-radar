# viral-radar

한국 언더그라운드 바이럴 곡 조기 탐지. 스포티파이 Viral 차트 폐지 대체용.

## 뭘 보는가

조회수가 아니라 **서로 다른 채널이 같은 곡의 가사/1시간/슬로우 영상을
얼마나 빨리 올리기 시작했는가**를 본다.

조회수는 살 수 있지만 서로 모르는 채널 수는 사기 어렵다.
스포티파이가 Viral 차트를 접은 이유가 AI 스팸/조작이었는데,
이 지표는 그 오염을 구조적으로 피해간다.

Shazam 한국 200은 **진입 신호가 아니라 퇴장 신호**로 쓴다.
거기 이미 올라온 곡은 대중까지 넘어간 뒤라 커버 타이밍상 늦었다.

## 결과 보는 곳

- `LATEST.md` — 항상 최신 리포트
- `reports/YYYY-MM-DD.md` — 날짜별 기록
- `state/history.json` — 곡별 누적 상태 (건드리지 말 것)

## 실행

매일 새벽 6시(KST) 자동. 수동으로 돌리려면
Actions 탭 → "바이럴 레이더 (매일)" → Run workflow.

## 설정 바꾸기

`scan.py` 맨 위 설정 구역만 고치면 된다.

- `QUERIES` — 검색어. 씬 태그 추가하고 싶으면 여기
- `LOOKBACK_DAYS` — 최근 며칠 업로드까지 볼지 (기본 21)
- `MIN_CHANNELS` — 후보 최소 채널 수 (기본 2)
- `TOP_N` — 리포트에 실을 곡 수 (기본 12)

## 필요한 Secret

- `YOUTUBE_API_KEY` — YouTube Data API v3 키
